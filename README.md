# Scrollegro

カーソルを乗せてスクロールするだけで、動画の速度を調整するPCアプリです。

[公開リリースとダウンロード](https://github.com/kk-1226/scrollegro-releases/releases)から、OS・CPUに合う配布物を選んでください。正式版の公開前はダウンロードできません。

[公式サイト](https://scrollegro.vercel.app)からも、公開後の対応OS向けインストーラーを直接取得できます。

このリポジトリでは配布案内のみをGit管理し、インストーラー・署名・更新情報はGitHub ReleasesのAssetsへ添付します。アプリのソースコード、ビルド用Actions、秘密鍵は含みません。
